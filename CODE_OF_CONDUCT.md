# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies in every space the project runs: issues, pull requests, discussions,
reviews, and anywhere someone represents the project.

In short: be respectful and constructive, assume good faith, and critique work, not
people. Harassment, personal attacks, and unwelcome sexual attention or language are not
acceptable.

## Reporting

Report conduct that breaks this code to the maintainer, @wyattrupp, through a private
channel on GitHub, not in a public thread. Reports are handled in confidence. The
maintainer may edit or remove contributions and warn, suspend or ban a participant, as
the Covenant's enforcement guidelines describe.
